# Scripts

One-off and maintenance scripts. Each script starts with a comment saying what it does and how to run it, and takes paths as arguments instead of hard-coding them.

| Script | Purpose |
|---|---|
| `icons.mjs` | Generate `favicon.ico`, `apple-touch-icon.png`, `icon-192.png`, `icon-512.png` from `public/favicon.svg` with Playwright screenshots |
